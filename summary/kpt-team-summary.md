# 팀 KPT 회고 — 발표 요약

**교육** Cursor AI를 활용한 소프트웨어 개발  
**회고** KPT (Keep · Problem · Try) — 팀 6명 개인 회고 취합  
**발표** 약 3~5분

---

## 발표 순서

1. Keep — 잘 된 점  
2. Problem — 어려웠던 점  
3. Try — 다음에 바꿀 점  
4. 마무리

---

## Keep — 유지할 것

**핵심 메시지**  
단계를 나누고, 규칙을 고정하고, 기록을 남기면 Agent와 TDD가 잘 맞았다.

### 프롬프트 · 워크플로

| | |
|---|---|
| **Phase 분리** | RED / GREEN / REFACTOR를 한꺼번에 요청하지 않고, 「지금은 RED만」처럼 범위를 좁혔다. |
| **맥락·규칙 선언** | 슬래시 커맨드·ARRR 단계를 먼저 밝히고, 반복 전제는 Rule·Skill로 고정했다. |

### 학습 · 기록

| | |
|---|---|
| **Report + Transcript** | 단계마다 보고서와 대화 기록을 남겨, 다음 세션 맥락이 이어졌다. |
| **Agent와 학습** | 모르는 개념을 Agent와 함께 파악하며 작업 환경을 직접 구축할 수 있었다. |

### TDD · 리뷰

| | |
|---|---|
| **단계 게이트** | RED는 fail, GREEN은 최소 구현, skip 없이 진행했다. |
| **리팩터 패턴** | 1스멜 1커밋 → pytest 확인 흐름이 안정적이었다. |

---

## Problem — 문제점

**핵심 메시지**  
AI는 빠르지만, 판단·구조·브랜치·리뷰는 사람이 먼저 잡아야 했다.

### 이해 · 판단

| | |
|---|---|
| **개념·약어** | TDD, Dual-Track, ARRR, Golden Master 등 용어가 많아 실습과 이해를 동시에 따라잡기 어려웠다. |
| **구조 검증 부족** | 테스트 통과만 보고 AI 제안을 수용했다가, 리뷰에서 되돌리는 경우가 있었다. |
| **사람 판단** | spec·SSOT·모호한 요구는 AI만으로 정리되지 않았다. |

### 프로세스 · 협업

| | |
|---|---|
| **브랜치·Phase 혼선** | red / green / staging 역할 혼동, 한 PR에 여러 Phase가 섞였다. |
| **리뷰·협업** | PR 맥락 부족, 동료 리뷰 시간 부족으로 Agent 리뷰에 의존했다. |

### 도구 · 환경

| | |
|---|---|
| **툴 미숙** | Cursor 워크플로, Mom Test·페르소나 활용이 익숙하지 않았다. |
| **환경 이슈** | git 등 환경 문제로 작업 흐름이 끊긴 적이 있었다. |

---

## Try — 시도할 것

**핵심 메시지**  
한 Phase · 한 산출물 · 한 검증 — **사람이 판단, Agent는 실행.**

| # | 행동 |
|:-:|------|
| 1 | 요청을 **「한 Phase + 완료 조건」** 으로 쪼개고, 「지금은 ○○ 단계」를 먼저 선언한다. |
| 2 | AI 코드 제안 전 **「왜 이 구조인지」** 를 확인한다. spec·SSOT는 사람이 기준을 정한 뒤 Agent에 맡긴다. |
| 3 | **브랜치·PR 체크리스트** — base 재확인, Phase별 커밋 분리, PR 본문에 목적·범위·Report 링크를 넣는다. |
| 4 | REFACTOR는 **1스멜 → pytest 확인 → 다음**. 기준선 없이 시작하지 않는다. |
| 5 | **SW 기본기 스터디**를 Agent 활용과 병행하고, 단계 마감 시 Transcript Export를 포함한다. |

## 마무리

| | |
|---|---|
| **Keep** | Phase 분리 · Rule 고정 · 기록 — Agent와 TDD를 함께 쓰는 **방법**을 배웠다. |
| **Problem** | 빠른 AI 속에서 **구조 이해 · 브랜치 관리 · 사람 리뷰**가 병목이었다. |
| **Try** | Agent는 **실행**, 사람은 **판단 · 검증 · 기록** — 이 역할 분담을 다음에 가져간다. |
